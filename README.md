## 📦 Getting Started

### Prerequisites
- Node.js 18.17+ or newer (Tested on Node.js v25)
- npm 9+

### Installation
```bash
# Clone the repository
git clone https://github.com/zarak-dev/portfolio.git
cd portfolio

# Install dependencies
npm install

# Launch development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the Developer OS.

### Production Build & Type Check
```bash
# Verify TypeScript typings
npm run typecheck

# Create optimized production build
npm run build

# Start production server
npm run start
```
